# 오늘 배운 것

클로드 코드(Claude Code)와 함께 이 블로그를 처음부터 만들어보면서, HTML·CSS·JavaScript가 각각 어떤 역할을 맡는지 다시 한번 명확하게 정리할 수 있었습니다.

## HTML — 구조와 뼈대

HTML은 페이지에 어떤 요소들이 존재하는지, 그 요소들이 어떤 의미를 가지는지를 정의합니다. 이 블로그에서는 `index.html`과 `post.html` 단 두 개의 뼈대만 만들고, 실제 글 목록과 본문은 자바스크립트가 그때그때 채워 넣는 구조를 택했습니다. 즉 HTML은 "껍데기"를 미리 준비해두고, 콘텐츠는 나중에 주입되는 방식입니다.

## CSS — 테마와 반응형을 담당

CSS는 눈에 보이는 스타일을 담당하지만, 이번 프로젝트에서 특히 인상 깊었던 부분은 **커스텀 프로퍼티(`--bg`, `--text` 같은 변수)** 로 라이트/다크 테마 값을 분리해둔 점입니다. 자바스크립트는 `data-theme` 속성 값만 바꾸고, 실제 색상 전환은 전부 CSS가 알아서 처리합니다. 반응형 레이아웃도 미디어 쿼리 하나로 모바일 폭까지 자연스럽게 대응할 수 있었습니다.

## JavaScript — 데이터를 가져와 화면을 조립

가장 많은 역할을 한 것은 자바스크립트였습니다.

- `fetch()`로 마크다운 파일과 매니페스트(`manifest.json`)를 읽어오고
- `marked.js`로 마크다운을 HTML로 변환하고
- 그 결과를 DOM에 렌더링하고
- 검색·태그 필터·다크모드 토글 같은 상호작용을 처리하는 것

모두 자바스크립트의 몫이었습니다. 프레임워크 없이도 `fetch`, `URLSearchParams`, `localStorage` 같은 브라우저 기본 API만으로 꽤 많은 것을 할 수 있다는 걸 체감했습니다.

## 정리

결국 세 언어의 역할은 이렇게 요약됩니다.

| 언어 | 역할 |
| --- | --- |
| HTML | 콘텐츠가 들어갈 구조를 정의 |
| CSS | 보이는 방식(색상, 레이아웃, 테마)을 정의 |
| JavaScript | 데이터를 가져오고, 조립하고, 사용자 상호작용을 처리 |

각자의 역할이 분리되어 있으니 코드도 이해하기 쉽고, 어디를 고쳐야 할지 헷갈리지 않는다는 점이 좋았습니다.
